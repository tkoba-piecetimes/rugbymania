ラグビーのルール改正【2026年最新】日本協会の通達で整理

「ラグビーのルールがまた変わったと聞いたけれど、何がいつから変わったのか分からない」。秋のシーズン中に、現役部員やマネージャー、保護者の方からこうした疑問が出ることがあります。この記事では、2026年に日本ラグビーフットボール協会（JRFU）が加盟協会向けに出した通達を中心に、確認できた改正内容を発出日・施行日つきで整理します。

ルールは年度や大会、カテゴリーによって適用が異なる場合があります。この記事で書くのは、協会の公式ページで確認できた範囲です。確認できなかった点は、その旨を明記します。

結論：2026年の通達は4件、施行時期がそれぞれ違う

2026年に協会の公式ページで確認できた競技規則関連の通達は、次の4件です。

発出日通達の内容施行・適用の時期
2026年5月18日競技規則の適用ガイドライン（モールボールを持った選手を中心に、両チーム1人以上が立ったまま組み合い、持ち上げたボールを押し合う状態。用語辞典で見る）2026年6月1日以降に始まる新規大会から
2026年6月15日ルーリング2026-2（第15条ラック地面にあるボールの上で、両チーム1人以上が立ったまま組み合い、ボールを奪い合う状態。手は使えない。用語辞典で見る）通達に基づき運用
2026年7月15日世界的試験実施ルールの正式採用・競技規則改正2026年7月1日
2026年8月27日タックルボールを持つ相手をつかんで地面に倒すプレー。倒したあとは、すぐにボールから離れなければならない。用語辞典で見るの高さに関する競技規則改正に伴う適用通達記載の適用方針に従う

通達の発出日と施行日がずれているものがある点に注意が必要です。たとえば7月15日付の通達は、施行日が7月1日になっています。「発表された日」と「ルールが有効になった日」は別に確認する必要があります。以下、それぞれを順に見ていきます。

2026年7月1日施行：試験実施ルール4つが正式な競技規則に

正式採用された4項目

協会の2026年7月15日付の通達によると、ワールドラグビーの特別理事会および年次理事会で承認された、以下の4つが競技規則として正式に採用されました。

  1. スクラム試合が止まったあとの再開方法。両チーム8人ずつが体を組み合わせて向かい合い、間に入れたボールを足で奪い合う。用語辞典で見るのブレーキフット（競技規則19.10〜19.12）
  2. ウォーターキャリアおよび追加人員の制限（競技規則6.29）
  3. テレビジョンマッチオフィシャル（TMO）（競技規則6.15・6.16）
  4. 20分レッドカード重い反則をした選手に出される退場の合図。その選手は、その試合にもう出られない。用語辞典で見るによる交替（競技規則9.30）

通達はあわせて、軽微な競技規則の改正と、コミュニティーラグビーにおけるタックルの高さの引き下げについても、施行日を2026年7月1日と示しています。

ブレーキフットとは

ブレーキフットは、スクラムでフッカー2番のポジション。スクラムの中央でボールを足でかき出し、ラインアウトでは投げ入れ役も務める。用語辞典で見るが足の位置を工夫して安定性を保ち、首や頭に軸方向の負荷がかかるのを避けるための取り決めです。協会が2024年2月に出したルーリング2024-1では、プレーヤーの安全を目的とする試験実施ルールとして扱われており、フッカーが「ブレーキ」の位置に足を置くこと、レフリーが「セット」をコールするまでその役割を果たすことが説明されています。2026年7月からは、この考え方が試験ではなく正式な規則になりました。

スクラムの組み方そのものを練習で見直す場合は、ラグビーのスクラム技術と練習方法も参考になります。

20分レッドカードとは

ワールドラグビーの発表では、20分レッドカードは、レッドカードを受けた選手をそのまま退場とするのではなく、一定時間のオフフィールドでの措置を経て、20分後にチームが交替選手を入れられる仕組みとして説明されています。14人で長時間戦うことによる試合の一方的な展開を抑える狙いがあるとされています。

通達に記載されているのは「20分レッドカードによる交替」を競技規則9.30として採用するという点です。大学の各大会で細かな運用がどうなるかは、通達の本文だけでは読み取れません。該当する大会の要項や、試合前の審判団の説明で確認してください。

ウォーターキャリアとTMO

ウォーターキャリアおよび追加人員の制限は、試合中にピッチ内へ入る人の扱いに関する規則です。TMOは映像を使った判定の仕組みです。通達で確認できたのは、それぞれ競技規則6.29、6.15・6.16として正式採用されたという事実までです。映像判定のシステムがない大学の試合では、TMOが使えないことも考えられます。試合ごとに運営側へ確認するのが確実です。

2026年8月27日付：タックルの高さに関する通達

エリートとコミュニティで制裁ラインが違う

部員や保護者にとって影響が大きいのがタックルの高さです。協会の2026年8月27日付通達は、ワールドラグビーの改正を受けて、国内での適用を次のように整理しています。

  • エリートラグビー（通達ではジャパンラグビーリーグワン）：肩のライン
  • コミュニティーラグビー（エリートラグビー以外）：胸骨の下端部分

タックラーには、該当する制裁ラインより下をタックルする責任があるとされています。通達はあわせて、変則規則「GAME-ON」は国内では採用しないこと、必要に応じて検証し改訂やガイドラインの変更を行う方針であることを示しています。アンダー世代については、国内独自の規則が適用されていることがあるため、年代別ラグビー競技規則補則を参照するよう案内されています。

大学ラグビーはどちらに当たるのか

通達の区分は「リーグワン」と「それ以外」の2つで、大学ラグビーを名指しした記述は、確認できた範囲にはありません。通達の文言どおりに読めば、リーグワンではない大学の試合はコミュニティーラグビー側の区分に当たると考えられますが、各地区協会や各大会が要項でどう扱うかは、この記事では確認できていません。関東であれば、関東ラグビーフットボール協会の大会要項や連絡事項で確認してください。

練習で意識したいこと

制裁ラインが決まると、タックルの練習では「どの高さに入るか」を事前に決めておく価値が高まります。低く入る動きの練習については、ラグビーのタックル練習のコツを参照してください。また、頭部のケガが疑われる場面の対応は、ラグビーの脳震盪対応と段階的競技復帰で整理しています。

2026年6月1日以降の新規大会：モールの適用ガイドライン

2026年5月18日付の通達は、モールへの参加の仕方に関する適用ガイドラインを示しています。施行は、2026年6月1日以降に始まる新規大会からとされています。

基本原則として、通達には次の趣旨が書かれています。

  • モールに参加するときは、モールの最後尾のプレーヤーにバインド腕を使って、味方や相手の体につかまって組むこと。スクラムやラック、モールで必要になる。用語辞典で見るする
  • 2人以上でチェーンを形成し、横や外側から回り込むように参加しない
  • 合法的なバインドを失ったあとも参加し続けない
  • ボールの争奪に直接関与していないプレーヤーは参加しない

バインドは、手から肩までの腕全体が接触し、胴体部分をしっかりつかむ状態とされています。「新規大会から」という書き方なので、すでに始まっていた大会（たとえば6月1日より前に開幕した大会）にいつから適用されるかは、通達だけでは分かりません。秋のリーグ戦関東の大学ラグビーのもう一つの大会区分。1部・2部など「部」に分かれて戦う。用語辞典で見るに適用されるかどうかは、大会主催者への確認が必要です。

2026年6月15日付：ラックのルーリング2026-2

ルーリング2026-2は、競技規則第15条（ラック）に関するワールドラグビーの指示を受けた通達です。協会のページによれば、スクラムハーフ9番のポジション。人が固まった場所からボールを取り出し、味方へパスして攻撃を始める。用語辞典で見るがラックの最後尾の足より後方に位置してボールを手で動かす行為について、規則の文言上は違反に見えるものの、実質的な不正なプレーとは認められない場合がある、という整理です。

注意したいのは、この解釈が「ボールの争奪が明らかに終了している場合にのみ適用される」とされている点です。争奪が続いている場面まで認められるわけではありません。あわせて、ボールが明確に確保された時点で、レフリーが速やかに「ユーズイット」をコールするよう求められています。スクラムハーフを務める部員は、レフリーのコールの出方と合わせて動きを確認しておくとよいでしょう。

現場で確認したいチェックリスト

ここまでの内容を、チームで確認する際の項目に落とし込みます。

  1. 参加する大会の要項に、2026年7月1日施行の改正が適用される旨があるか
  2. タックルの制裁ラインが、その大会でどの高さになっているか（肩か、胸骨の下端部分か）
  3. 20分レッドカードの運用や、TMOの有無について、試合前に運営から説明があるか
  4. 練習試合の相手校が、同じルール適用で運営しているか
  5. 新入生や保護者向けの資料が、旧ルールのままになっていないか

マネージャーや学生コーチにも関係があります。ウォーターキャリアなど、ベンチ側の人の動きに関わる規則があるため、試合当日の動き方を確認する場面が出てくる可能性があります。役割の全体像はラグビー部マネージャーの仕事内容と1日の流れにまとめています。

用語が分からないときは

ブレーキフット、ユーズイット、ラック、モールなどの用語に不安がある場合は、ラグビー用語集（初心者向け）で基本を確認できます。

ルールの変更は、順位表の見方にも影響するのか

今回確認した通達は、タックルやスクラム、モール、ラックといったプレーの扱いを定めたものです。勝ち点試合の結果に応じて与えられるポイント。シーズンの合計が多い順に順位が決まる。用語辞典で見るの付け方や、リーグ内の順位決定の方法を直接変えるものとは、確認した範囲では読み取れませんでした。順位の決まり方は大会ごとの規定によるため、ボーナスポイント勝敗とは別に、大差の勝利や僅差の敗戦などで加わる勝ち点。条件は大会ごとに決まっている。用語辞典で見るの考え方は大学ラグビーの順位表とボーナスポイントの見方で整理しています。

シーズン中の試合結果や順位は、ラグビーマニアの一次データページで確認できます。対抗戦関東の大学ラグビーの大会区分の一つ。Aグループ・Bグループに分かれて戦う。用語辞典で見るAグループなら順位表と日程・結果、リーグ戦1部なら順位表と日程・結果を用意しています。新しいルールのもとで、試合の中身や反則の傾向が変わっていくのかどうかは、シーズンを通して試合を見ながら確かめていく部分です。この記事では、結果への影響について断定しません。

この記事で確認できていないこと

誤解を避けるため、確認できていない点を整理しておきます。

  • 2026年7月15日付通達の「軽微な競技規則の改正」の個別項目は、附属文書で示されています。本稿では個別の中身を取り上げていません。
  • 大学リーグ（関東・関西・九州）の各大会が、これらの改正をいつ、どの形で適用するかは、大会要項の確認が前提になります。
  • 高校以下のカテゴリーは、年代別の補則が適用される場合があり、この記事の対象外です。
  • 2026年版の競技規則の条文そのものは、協会の競技規則一覧のページからPDFで確認できます。

ルールの条文や解釈で迷ったときは、協会の公式ページ、または所属する地区協会の審判関係の窓口に問い合わせるのが確実です。

まとめ

2026年は、5月のモール、6月のラック、7月の試験実施ルールの正式採用、8月のタックルの高さと、通達が続いた年です。確認できた事実は次のとおりです。

  • 2026年7月1日施行で、ブレーキフット、ウォーターキャリアなどの制限、TMO、20分レッドカードが正式な競技規則になった
  • タックルの制裁ラインは、リーグワンが肩、それ以外のコミュニティーラグビーは胸骨の下端部分と通達に示された
  • モールは新規大会から、ラックはルーリングで、それぞれ運用が整理された
  • 大学の各大会への具体的な適用は、大会要項で確認する必要がある

通達は発出日と施行日がずれることがあるため、ニュースの日付だけで判断せず、施行日と大会の開始時期を照らして確認してください。
