ラグビーの試合後リカバリー｜睡眠・休養日の考え方を大学生向けに整理

「試合の翌日は体が重くて、そのまま火曜の練習に入るとキレが出ない」「週末の試合から次の試合までの間に、何をすれば疲れを残さずに済むのか分からない」。シーズンが進み、リーグ戦関東の大学ラグビーのもう一つの大会区分。1部・2部など「部」に分かれて戦う。用語辞典で見るや対抗戦関東の大学ラグビーの大会区分の一つ。Aグループ・Bグループに分かれて戦う。用語辞典で見るが続く時期になるほど、こうした悩みを持つ部員は増えやすいものです。ラグビーは接触が多く、試合のたびに筋肉や関節にダメージが残ります。練習量を増やす前に、試合後の回復をどう設計するかが、シーズン後半のコンディションを左右する場合があります。

この記事では、ワールドラグビー（国際統括団体）が公開している「試合間の推奨休養」と、同団体の教育サイト「Passport」に掲載されている睡眠の資料をもとに、大学ラグビー部員がリカバリーを考えるときの要点を整理します。あわせて、1週間の組み立て方の例と、部内で確認したいチェックリストも紹介します。

なお、回復の進み方や必要な睡眠時間には個人差があります。痛みや腫れ、しびれ、頭部への衝撃の疑いがある場合は、この記事の内容より先に、トレーナーや医療機関への相談を優先してください。

試合後リカバリーで最初に知っておきたい「4日」という目安

ワールドラグビーは2023年3月20日付けの「試合間の推奨休養」ガイドラインで、試合後には少なくとも4日間の完全な回復日を確保することを推奨しています。ページでは、3日間では不十分とされ、前の試合の4日後に次の試合を入れないことが望ましいと説明されています。例として、土曜日に試合をした場合、次の試合は早くても木曜日、という考え方が示されています。

また、試合の直後に休養または非常に軽い練習の日を置き、次の試合の前にも軽い日を置くことが、主催者向けの計画として挙げられています。

このガイドラインを読むときに押さえておきたいのは、次の点です。

  1. 背景となる知見: 筋力やジャンプなどの神経筋のパフォーマンスは、試合後に少なくとも60時間、研究によっては最大5日間低下したままになる場合があると紹介されています。筋損傷の指標も4〜5日続く場合があるとされています
  2. 根拠には限界がある: ページ自身が、試合後の回復と怪我のリスクを直接結びつけた研究はないと明記しています。また、研究の多くはセブンズやラグビーリーグ、ジュニアやサブエリートの選手を対象としており、15人制のデータは限られるとされています
  3. 4日あっても完全に回復するとは限らない: 4日の休養日を確保しても、完全に回復しない選手がいる可能性にも触れられています
  4. 運営面の制約も認めている: すでに組まれた大会日程では実現が難しい場合があることや、採用に向けた協議・移行期間を設ける予定であることも書かれています

つまり、「4日空ければ安全」ではなく、「疲労が残りやすい期間を意識して、練習の強度を調整する材料にする」という読み方が、現時点では誤解が少ないでしょう。この数字は、エリート選手やサブエリート選手を中心とした研究に基づく国際的な目安であり、日本の大学ラグビー部の公式戦がこの基準を満たしているかどうかは、ここでは判断していません。

自分たちのシーズンの試合間隔を確認する

試合間隔は、リーグや年度によって異なります。ラグビーマニアでは、関東・関西・九州の協会が公開している試合結果をもとに、日程と結果のページを用意しています。たとえば、関東大学対抗戦Aグループの日程・結果、関東大学リーグ戦1部の日程・結果、関西Aリーグの日程・結果では、各校の試合日を並べて確認できます。

こうした一次データを見ながら、「次の試合まで中何日あるか」を数えておくと、練習の強度を決めるときの根拠になります。順位や勝敗の進み具合は関東大学対抗戦Aグループの順位表や関東大学リーグ戦1部の順位表でも確認できます。

ただし、日程表から読み取れるのは試合日と対戦相手、結果までです。特定のチームの疲労の度合いや、休養日の過ごし方までは分かりません。日程は協会の発表や、天候・会場の都合で変更される場合もあるため、最新の情報は各協会の公式サイトで確認してください。

睡眠｜リカバリーの土台として考える

ワールドラグビーのPassportでは、睡眠を回復のための重要な要素のひとつとして紹介しています。ここでは、ページに書かれている内容を、断定を避けながら整理します。

睡眠時間の目安

Passportの睡眠ページには、複数の研究で「1晩8時間未満の睡眠が怪我のリスクの上昇と関連していた」という趣旨の記載があります。一例として、若いアスリート112名を対象にした研究（Milewskiほか、2014年）では、1晩8時間未満の睡眠で怪我のリスクが110％高かったと紹介されています。一方で、同じページには、ユースのサッカー選手75名を対象に、睡眠の長さや質が怪我の有意な予測因子ではなかったとする研究（Watsonほか、2017年）も並んでいます。

つまり、睡眠時間と怪我の関係は、研究によって結果が分かれています。「8時間眠れば怪我をしない」とは言えませんが、「睡眠が短い状態が続くことは、避けたほうがよい条件のひとつとして扱われている」と理解するとよいでしょう。別の教育ページでは、8時間という目安が「多くの人にとっておおむね適切」とされつつ、必要な睡眠時間には個人差があるとも書かれています。

試合の前週に睡眠を延ばした研究

Passportでは、エリートのラグビーユニオン選手68名が試合前の1週間に睡眠を補った結果、試合後の回復が改善したという報告（Hennessy、2011年）も紹介されています。睡眠の延びは1日あたり平均45分ほどで、主に午後の昼寝や試合前の昼寝、練習時の昼寝で確保されたとされています。

大学生の場合、授業や課題、アルバイト、早朝練習などで、まとまった睡眠を取りにくい時期もあるでしょう。この研究は、まとまった睡眠が取れなくても、短い昼寝を組み合わせて合計の睡眠を増やす考え方があることを示しています。ただし、対象はエリート選手であり、大学生にそのまま当てはまるとは断定できません。

昼寝と睡眠環境のポイント

Passportには、昼寝について、夜の睡眠を妨げないよう長すぎない時間にとどめ、遅くとも午後の早い時間までにする、という趣旨の記載があります。睡眠環境については、次のような項目が紹介されています。

  • 部屋を静かで暗くし、室温を約18度に保つ
  • 暑くなりすぎる寝具を避ける
  • 就寝・起床の時刻をなるべく一定にする
  • 寝る前のカフェインや飲食を避ける
  • 就寝前のテレビ・パソコン・タブレットなど、ブルーライトを出すものを控える

すべてを一度に取り入れる必要はありません。寮や共同の部屋で暮らしている部員は、室温や照明を自分だけで決められない場合もあります。できる項目から、1つずつ試してみてください。寮生活の実態は、大学ラグビーの寮生活についての記事でも整理しています。

食事・水分｜「量」より先に、試合後に準備しておく

ワールドラグビーの「試合間の推奨休養」ページでは、主催者が提供しうる回復手段の例として、マッサージ、アイシング、質の高い栄養補給の選択肢が挙げられています。具体的な摂取量やタイミングの数値は、このページには書かれていません。

数値の目安は、個人の体重・練習量・体調で変わるため、この記事では示しません。一般的にいえるのは、試合後に何も食べられない状況をつくらないために、あらかじめ補食を用意しておく、という準備の考え方です。チームでの栄養補給の体制や量の決め方は、部のトレーナーや管理栄養士に確認してください。体重管理や増量を目的とした食事の考え方は、増量の食事メニューの記事にまとめています。夏場の水分補給や中止の基準は、熱中症対策の記事を参照してください。

1週間の組み立て例｜試合日を起点に考える

ここでは、土曜日に試合がある場合の一例を示します。あくまで考え方の例であり、実際の練習内容や強度は、コーチ・トレーナーの判断に合わせてください。

曜日位置づけ考えたいこと
日試合の翌日休養または非常に軽い運動。睡眠時間を確保し、痛みや違和感を共有する
月回復日強いコンタクトは避ける考え方がある。体の状態の確認を優先する
火回復日状態を見ながら、戻せる部員から段階的に負荷を戻す
水回復日負荷は戻し始めつつ、疲労が残る部員は調整する
木次の試合へ向けた準備試合の準備を進める日。ワールドラグビーの目安では、次の試合が早くて木曜日
金軽めの調整次の試合の前に軽い日を置く考え方がある。睡眠を優先する
土試合試合前後の補食・水分の準備を済ませておく

試合間隔が1週間より短い大会や、連戦になる時期には、この表のようには組めません。その場合は、負荷を下げる日を明確に決めることと、出場時間の長い部員を中心に、休養日の過ごし方を共有しておくことが大切です。

試合や練習でのウォームアップの工夫は、ワールドラグビーのActivateを使った怪我予防の記事で扱っています。ハムストリングなど、疲労が残りやすい部位の予防の考え方は、ハムストリング肉離れ予防の記事も参考になります。

「回復が間に合っていない」ときの確認点

次のような状態が続くときは、疲労が残っている可能性があります。ただし、これらの症状だけで原因を判断することはできません。

  • 練習の動き出しが重く、普段より加速できない
  • ジャンプやダッシュの感覚が落ちている
  • 寝つきが悪い、あるいは朝起きても休めた感じがしない
  • 同じ部位に痛みや張りが何日も続いている

こうした場合は、無理に練習量を維持せず、コーチやトレーナーに伝えて、練習への参加方法を相談しましょう。痛みを我慢して練習を続けると、状態が悪化する場合があります。

特に、頭部への衝撃があった場合は、疲労とは別の問題として扱う必要があります。頭を打った可能性があるときは、その日の練習・試合から外れ、段階的に復帰する手順が求められます。詳しくは脳震盪対応と段階的競技復帰の記事で整理しています。

マネージャー・学生コーチができること

回復は選手個人の努力だけでなく、部全体の運営でも変わります。マネージャーや学生コーチが関わりやすい点を挙げます。

  • 試合日程から、次の試合までの日数を一覧にして、部内に共有する
  • 試合後の補食・飲み物を、あらかじめ用意しておく
  • 出欠表とあわせて、「痛みや違和感」を伝えやすい記録の欄をつくる
  • 試合翌日の過ごし方を、トレーナーと相談して共有する

マネージャーの1日の流れについては、マネージャーの仕事内容の記事、学生コーチの役割は学生コーチの記事で整理しています。

部内で確認したいチェックリスト

  • [ ] 次の試合までの日数を、全員が把握できる形で共有しているか
  • [ ] 試合の翌日は、休養または非常に軽い運動の日として扱っているか
  • [ ] 試合後に食べられる補食と水分を、事前に用意しているか
  • [ ] 睡眠が極端に短くなっている部員が相談しやすい雰囲気があるか
  • [ ] 痛みや違和感を、トレーナーやコーチに伝える手順が決まっているか
  • [ ] 頭部への衝撃があった場合の対応を、全員が確認しているか

まとめ

試合後のリカバリーは、特別な方法を足すよりも、休養日・睡眠・補食という基本を、試合日程に合わせて計画的に組むことから始まります。要点を振り返ります。

  • ワールドラグビーは、試合後に少なくとも4日間の完全な回復日を推奨している。ただし、怪我との直接の関連を示した研究はなく、対象や条件にも限りがある
  • 睡眠は、8時間という目安が紹介される一方、研究によって結果は分かれる。個人差もある
  • 試合前の1週間に昼寝などで睡眠を補った研究があるが、対象はエリート選手で、大学生にそのまま当てはまるとは断定できない
  • 補食や水分は、試合後に慌てないよう、事前に準備しておく。量や内容はトレーナーや管理栄養士に確認する
  • 痛みや頭部への衝撃があるときは、リカバリーの工夫より先に、専門家への相談を優先する

まずは、次の試合までの日数を数えるところから始めてみてはいかがでしょうか。
