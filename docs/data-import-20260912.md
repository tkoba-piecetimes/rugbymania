## 変更
- rowspan/colspan、月日が結合された列、7/8列のCSSグリッド、チーム名内のbr、第二ステージに対応。
- メンバー表公開後に関東の日程が消える問題を修正。
- Cリーグ/リーグC表記揺れ、曖昧日程を保持。不戦・棄権・中止は架空スコアに変換しない。
- 取得失敗・ゼロ件・ID重複を検出した場合は既存データを空で上書きせず、更新処理を失敗として通知。
- チームスラッグはpykakasiが使えない場合に中断し、ランダムなURLを生成しない。
- 旧チームURLは年度横断データベースへの入口として保持。
- 順位表はスコアのある試合の参考集計。複数ステージは合算、公式勝ち点・最終順位とは異なるため明示。
