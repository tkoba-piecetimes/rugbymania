# SERP分析メモ: ラグビー 脳震盪 対応 段階的競技復帰

- 上位（共通点）: 日本ラグビーフットボール協会公式通達（GRTP改訂）、World Rugbyの脳振盪ガイダンス・PDF、地区協会（福岡県ラグビーフットボール協会等）の解説ページ、リーグワン公式（HIAプロトコル）が占め、検索意図の正解は「症状が出たら即プレー除外→医療機関受診→段階的に強度を上げて復帰」という公式プロトコルの正確な理解と、年代・既往歴で復帰までの期間が変わる点の把握。
- 欠けている要素: 上位は協会・専門機関の一次情報そのもの（通達文・PDF）が中心で、大学生プレーヤーや保護者が実際に部内でどう動けばよいか（誰に報告するか、部活動を休む間の過ごし方、周囲の部員が気をつけること）を平易に噛み砕いた解説が薄い。また自サイトのような大学ラグビー特化メディアで、脳震盪発生後に「試合復帰の可否」を判断する材料として自サイトの試合日程・チームページへ接続する導線を持つ記事は見当たらない。
- 差別化方針: 具体的な日数・段階の基準値は独自に創作せず「協会公式ページ・World Rugby公式資料で必ず確認する」設計とし、大学生プレーヤー目線で「疑ったらすぐプレーをやめる」「自己判断で復帰しない」という行動原則と部内での動き方を整理する。本文中で自サイトの一次データページ（対抗戦A日程・関西Aチーム一覧）へ内部リンクし、復帰後に試合日程を確認する導線を作る。
