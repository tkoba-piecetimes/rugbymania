# SERP分析メモ: ラグビー ハムストリング 肉離れ 予防（P・怪我と予防）

調査日: 2026-11-13

- 上位傾向: 整形外科・メディア系の一般的な肉離れ解説（応急処置RICE、重症度、復帰の目安）と、学位論文・科研費報告など研究系の抄録が混在。ラグビー大学生向けに「受傷場面」「予防」「復帰判断」を一体で整理した読みものは見当たらなかった。
- 差別化: 科研費報告（帝京平成大学・大垣亮氏、課題19K19983）が示す「ラグビーでは単純なスプリント以外（ステップ・ハンドリング・コンタクト）でも発生する」という受傷場面の整理を軸に、World Rugby Activate（軟部組織損傷26〜40%減の報告）、スポーツ安全協会の大学生外傷統計、メディカルノート（RICE・復帰の考え方）を出典付きで組み合わせ、自サイトの日程・順位表で試合間隔を確認する導線を付ける。
- 注意: 復帰日数・発生率などの数値は一次資料の全文で確認できなかったため記事に載せない。治療・復帰の最終判断は医師・理学療法士に委ねる書き方にする。
