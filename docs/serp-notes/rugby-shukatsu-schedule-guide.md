# SERP分析メモ: 大学ラグビー部員の就活スケジュール（③就活接続系）

作成日: 2026-09-22

## カテゴリ選定の経緯
既存の手動記事33本をcta別に集計すると、sponsor=18、career=5に対し、none=4・shukatsu=4・listing=4が並んで最少だった。このうちshukatsuを選び、既存の就活系4本（`rugby-shukatsu-appeal`＝自己PR全般、`rugby-manager-shukatsu-appeal`＝マネージャー、`rugby-non-regular-shukatsu-appeal`＝出場機会の少なさ、`rugby-quit-shukatsu-appeal`＝途中離脱）がいずれも「経験の言語化・自己PR」を主題にしている一方、「シーズンと就活の時期的な両立」という日程・スケジュール軸の記事が手薄だったため、この切り口を新規テーマとした。

## 検索意図
現役の大学ラグビー部員（特に3・4年生）が、対抗戦・リーグ戦のシーズン（9〜12月）と就活の本選考時期が重なることに不安を感じ、「いつから」「どう時間配分すべきか」を知りたいという意図。

## 事実確認
- シーズン日程: 関東ラグビーフットボール協会の公式発表「2026(R8)年度 関東大学ラグビー秋季公式戦日程のお知らせ」（https://www.rugby.or.jp/news/article/2695/）を一次情報とし、対抗戦Aグループ9/12開幕・12/6最終節、リーグ戦1部9/13開幕・11/29最終節という日程はラグビーリパブリック等の報道内容と突き合わせて整合を確認した。
- 就活日程: 内閣官房「2027年度卒業・修了予定者等の就職・採用活動に関する要請」（広報活動3月1日〜、選考活動6月1日〜）を一次情報とし、政府スケジュールと実態の早期化傾向についても言及した。同じ出典は`rugby-quit-shukatsu-appeal.md`でも使用済みだが、本記事ではシーズン日程との対比という新しい切り口で用いている。
- 非公式まとめサイトの独自数値は本文に引用していない。

## 差別化要素
1. 既存の就活系記事が「経験の伝え方」中心なのに対し、本記事は「いつ・どう時間を配分するか」という日程設計に特化した。
2. 協会公式のシーズン日程と政府の就活日程要請という、性質の異なる2つの公式情報を突き合わせて具体的な時期の重なりを示した。
3. 学年別（1・2年、3年、3年秋〜4年、4年＝幹部学年）に分けて、それぞれで意識すべきことを整理した。
