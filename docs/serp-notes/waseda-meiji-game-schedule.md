## 3. 共通点（検索意図の正解）

1. 検索者が最短で欲しいのは「次の早明戦はいつ・何時・どこで」の3点。
2. あわせて「チケットはどこで買えるのか」「優勝争いにどう絡むのか」を知りたい層が続く。
3. 大学公式・協会公式は「1試合の告知」単位でしか情報を出さないため、シーズン全体の中での位置づけは読者が自分で組み立てる必要がある。

## 4. 上位陣に欠けている要素（差別化点）

1. **2026年度（12月6日）の情報が1ページに整理されていない**。上位の大半が2025年度以前の告知・レポートで、公式の国立競技場情報ページも2026年度分が未反映（更新日2025年12月3日）。
2. **会場表記「MUFG国立」の説明がない**。2026年1月から国立競技場の呼称が「MUFGスタジアム」（略称MUFG国立）になったことに触れた早明戦記事は上位に見当たらない。日程表の会場名を見た読者の「どこ？」に答えられる。
3. **早明戦が優勝争いに絡む条件を、同一シーズンの他カードの日程から読み解く記事がない**。自サイトは2026年度全28試合を保有しており、11月1日の帝京大対早稲田大、11月22日の帝京大対明治大、11月23日の早慶戦という前段の節目を提示できる。
4. **過去の直接対決データが自サイトの試合ページに集計済み**（2021〜2025年度の5試合）。Wikipediaは通算成績、大学公式は自校視点で、直近5年のスコアを日程記事の中で示す競合はいない。
