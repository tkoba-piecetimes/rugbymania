# SERP分析メモ: ラグビー 肩 脱臼 予防（P・怪我と予防）

調査日: 2026-11-16

- 上位傾向: 整形外科・医療情報サイトの一般的な肩関節脱臼解説（症状・整復・保存/手術療法）と、学位論文・学会誌抄録（再脱臼率、タックルフォーム）が中心。大学ラグビー部員向けに「受傷するタックル場面・再発しやすさ・予防・復帰判断」を一体で整理した読みものは見当たらなかった。
- 差別化: スポーツ安全協会のラグビー編（発生頻度・Passive Tackle・予防プログラム）を軸に、メディカルノート（関節唇損傷）、ドクターズ・ファイル（再発・手術・復帰目安）、木島ら(2009)の高校ラグビー部員調査を出典付きで組み合わせ、自サイトの日程・順位表・記録室へ誘導する。
- 注意: 復帰日数・再発率は一般論として出典付きで書き、個人の見通しは主治医へ委ねる。肩に特化した予防の有効性は断定しない。core.ac.uk/qlife/CiNii の記述は本文を取得できず未使用。
