# SERP分析メモ: ラグビー プロップ 練習メニュー

作成日: 2026-09-18

## 確認したクエリ
- 「ラグビー プロップ 練習メニュー」
- 「ラグビー プロップ 基礎 練習」

## 上位の顔ぶれ
- ジャックナイフラグビー（jackknife-rugby.jp）: プロップの役割・スクラム技術（姿勢・バインド・打ち込み）を体系的に解説する指導者向け記事。具体的なセット数・反復回数・進行表は明記なし。
- rugby-practice.click: スクラム強化・走力・モール/ラックの3本柱でメニューを紹介。ウェイト種目名の言及はあるが、経験者前提で初心者向けの基礎説明は薄い。
- 公益財団法人スポーツ安全協会（sportsanzen.org）: World Rugby「Rugby Ready」準拠の外傷・障害予防プログラム。スクラムを1人→2人→3人→5人→8人へ段階的に組む進行法、頚部の等尺性トレーニングなど、安全側からの一次情報として質が高い。
- その他: SBDアパレル・サントリーサンゴリアス選手コラム・中学生向け転職コラムサイトなど、断片的な情報が並ぶ。大学の新入部員・未経験者・コンバート組を対象に体系立てた記事は見当たらない。

## 共通点・欠けている要素（3行まとめ）
1. 共通点: スクラムの姿勢・バインド・打ち込みという技術原則と、首・肩・背中・下半身の筋力強化という2軸で構成される記事が大半。
2. 欠けている要素: いずれも「経験者が伸ばす」視点が中心で、大学から入部した未経験者・他ポジションからのコンバート組がゼロから安全に始める段階設計（人数を絞ったスクラム練習の順序、無理な重量設定を避ける考え方）を扱った記事がない。
3. 自サイトが持つ対抗戦/リーグ戦/関西/九州の一次データ（順位表・チームページ）と組み合わせて「自分のチームがどのカテゴリで戦っているか」を意識させる導線を持つ記事も存在しない。

## 差別化方針
- スポーツ安全協会が示す段階的スクラム練習（1人→2人→3人→5人→8人）を軸に、未経験者・コンバート組が最初の数週間でどう取り組むかを整理する。
- 具体的な重量・回数は個人差が大きいため断定せず、専門家・顧問への相談を促す（根拠と言い切りのルール順守）。
- 本文中に自サイトの一次データページ（対抗戦Aグループ・チームページ等）へのリンクを2本以上入れ、自チームの所属カテゴリを意識させる。
