- 初回メモ時点: 慶應・一橋・金沢大・大阪公立大の公式、jackknife-rugby（立教）、知恵袋、TikTok

## 記事型
- 各大学の「紹介」型が中心。横断まとめ型の自記事は型としては合っているが、「1日の流れ」を時刻で示す要素がない。

## 上位にあって自記事に弱い要素
1. 時刻つきの1日（東大TURFCは 6:30 準備 → 7:00 練習開始 → 9:00 ケア・翌日準備・動画アップ を公開）
2. 練習日と試合日の違いを一目で比べられる表
3. 「大変？」「未経験でも？」「勉強と両立できる？」のQ&A
4. 活動頻度は部によって大きく違う（例：週1〜2回の部もある）という幅の提示

## 自記事だけの要素（維持）
- 東大・大阪公立大・立教の公開情報を横断して場面別に整理
- 所属リーグの大学一覧ページへの導線、就活記事との相互リンク

## 対応方針（記事側）
- タイトルに「時刻つき」「練習日・試合日」を入れてCTR改善（意図は不変）
- 時刻つき1日の表、練習日/試合日比較表、FAQを追加
- 主務・マネージャー出身者キャリア・学生トレーナー/アナリストの記事へ内部リンク
- 根拠のない一般化（「〜な新入生は多いはず」等）を弱める

## 媒体側の論点
- 公式サイト（大学ドメイン）が多く並ぶSERP。被リンク・ドメイン評価は記事単体では埋まらない。
