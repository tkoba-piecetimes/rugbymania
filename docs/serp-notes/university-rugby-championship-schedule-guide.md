## 2. 共通点（検索意図の正解）

- 検索者が最優先で欲しいのは「何月何日に、どこで、どのラウンドがあるか」の一覧表。
- 準決勝（1月2日）・決勝（1月11日）と国立競技場という固有情報への関心が高い。
- 放送・配信（NHK・J SPORTS等）とチケットの導線も併せて求められている。

## 3. 上位陣に欠けている要素（差別化点）

1. **「2026年度（第63回）はまだ発表されていない」という現在地の明示がない。** 上位8件はすべて第62回（2025年度）の日程を掲載しており、2026年9月15日時点の検索者が「今年の日程」を探して着地すると前年の表を見せられる。→ 本記事は冒頭で未発表であることと、**いつ発表されるかの目安**（前年実績: 大会概要 2025-10-22、出場校・組み合わせ 2025-12-08）を示す。
2. **出場校が確定する日（＝各地区リーグの最終節）から日程を逆算する視点がない。** 2026年度の各リーグ日程はすでに発表済みで、対抗戦A最終日12月6日、リーグ戦1部最終日11月29日、関西A最終節11月28・29日、九州学生リーグ11月29日まで、という確定情報がある。→ 本記事だけの一覧表にできる。
3. **各地区リーグの順位表という一次データへの導線がない。** 上位は大会単位の情報に閉じており、「どの大学が出場権に近いか」を追える順位表を持たない。→ 自サイトの対抗戦A／リーグ戦1部／関西A／九州Aの順位表へ内部リンク。

## 4. 本記事の方針

- 「未発表である」ことを隠さず、前年の確定情報（第62回の全ラウンド日程・会場・出場枠）を**参照モデル**として提示する。前年情報を今年の日程として書かない。
- 出場ルート（対抗戦A・リーグ戦1部・関西A各3枠＋前年度優勝／準優勝校の所属リーグに各1枠、九州1、北海道・東北1、東海北陸中国四国1＝14チーム）を解説し、順位表への導線にする。
- 既存記事との棲み分け: `university-rugby-strong-universities-ranking`（強さ・勢力図）、`university-rugby-league-format-guide`（対抗戦とリーグ戦の違い）とは検索意図が異なる。本記事は「日程・スケジュールの追い方」に限定する。
- 更新型。2026年度の大会概要・組み合わせが発表され次第リライトする。
