## 共通点（検索意図の正解）
- キックの種類（パント／グラバー／ハイパント／ゴールキック等）の定義と使いどころ。
- ボールの落とし方（ドロップ）が重要という練習の基本。
- ライン沿いに蹴って精度を確かめる練習。

## 欠けている要素（差別化点）
1. 目的別（陣地・再獲得・崩す・得点・再開）の整理と、規則条文（8条・12条・18.8a/18.8d）の対応。
2. 蹴る人だけでなく追う人・捕る人まで含めた役割別の確認と、少人数から始める段階練習。
3. 一次データ（対抗戦A・リーグ戦1部・関西Aの順位表、日程、記録室）への導線と、データから読み取れない範囲の明記。
