## JRFU 通達（2022-08-26, news/51489）で確認した数値（記事に出典付きで転記可能）
| カテゴリ | 休養 | 最短復帰 |
|---|---|---|
| エリート（HIA対象試合） | 既往あり/HIA3陽性は最低12日 | 既往なし・HIA3陰性で7日目（ICC承認要） |
| エリート（練習・練習試合） | 1週間 | 最短14日 |
| 18歳以上コミュニティ（大学生含む・高校/高専除く） | 条件充足1週間/非充足2週間 | 最短14日 / 最短21日 |
| 高校・高専 | 従来通り | 最短3週間 |
| 中学生以下 | 従来通り | 最短23日 |

18歳以上で最短14日になる3条件: ①脳振盪の既往なし ②チーム内にSCAT5ベースラインあり ③受傷後36〜48時間にSCAT5実施しベースラインより悪化なし。添付: 2週間/3週間用の復帰証明書書式、SCAT5日本語版。

## 自記事に欠けている要素
1. 年代別の最短日数表（上表）と「大学生は14日 or 21日」の結論先出し
2. GRTPの段階表（Stage1〜6の運動内容・各段階24時間の原則）— World Rugby ガイドラインから出典付きで
3. SCAT5（ベースライン測定）と部での準備（大学生に最短14日を適用するための前提条件）
4. 復帰証明書（JRFU書式）の存在
5. FAQ（意識消失がなくても脳震盪？／ヘッドキャップで防げる？／学業・スマホは？）
6. 姉妹記事（ヘッドキャップ・首の強化・タックル・Activate・マウスガード）への内部リンク
