シーズン前の体力測定で「ブロンコをやる」と言われたものの、どんなテストなのか、何分なら良いのか、はっきり分からないまま走った人もいるのではないでしょうか。ブロンコテストはラグビーで広く使われている持久力テストですが、日本語で一次情報に当たって整理された解説は多くありません。この記事では、研究論文と公開されているテスト解説をもとに、やり方、タイムの見方、結果の使い方、測定前後の注意点をまとめます。なお、ここで紹介するタイムは「資料によって幅がある目安」です。自分のチームの基準は、コーチやトレーナーに確認してください。

## 結論｜ブロンコは「ラグビーの動きに近い持久力」を見る1.2kmのテスト

ブロンコテストは、20m・40m・60mの折り返しダッシュを1セットとして5セット、合計1,200mを全力で走り、その合計タイムを測るテストです。「1.2km シャトルラン」とも呼ばれます。長距離を一定ペースで走る持久走とは違い、加速、減速、方向転換を何度も繰り返す点が特徴です。

まず押さえておきたいのは次の4点です。

| 確認すること | 内容 |
| --- | --- |
| 何を測るか | 加速と方向転換を繰り返す高強度の持久力 |
| 距離と回数 | 20m・40m・60mの往復を1セット、これを5セット（合計1,200m） |
| 結果の見方 | 合計タイムが短いほど良い。ポジションや年代で目安が異なる |
| 注意点 | 資料により目安のタイムに差がある。自分の過去の記録との比較が実用的 |

## ブロンコテストのやり方

測定方法はテスト解説サイト[Topend Sports](https://www.topendsports.com/testing/tests/shuttle-1200m.htm)に整理されています。内容は次のとおりです。

- スタートラインから0m、20m、40m、60mの位置にマーカーを置く
- 20mの往復、40mの往復、60mの往復を続けて走る。これが1セットで、距離は240m
- 休まずに5セット続けて走り、合計1,200mとする
- 各ラインでは、足がラインに触れるか越えてから折り返す
- 1セットで折り返しは6回、5セット合計では30回になる
- スタートから全力で走る。ペース配分をしない前提のテストとして説明されている

使う道具は、ストップウォッチ、メジャー、マーカー（コーン）です。平らなグラウンドや芝生で行い、ラグビーのピッチが適しているとされています。同ページでは、実施前の健康状態の確認と十分なウォームアップを前提としています。

なお、一部の解説では「1セット300m、合計1,500m」と書かれている例があります。しかし、20m・40m・60mの往復で1セットは240mになり、5セットで1,200mです。論文のタイトルでも「1.2 km」と表記されていることから、1,200mとして扱うのが一般的です。測定前に、自分のチームが採用している距離とルールを確認しておくと安心です。

## なぜラグビーでブロンコが使われるのか

ラグビーの試合は、止まっている時間と全力で動く時間が入り混じります。ずっと同じ速度で走り続ける競技とは違い、タックルに入るための加速、ラックへの寄り、ディフェンスラインのセットなど、短い距離を繰り返し走る場面が多くなります。ブロンコは、この「短い全力走の繰り返し」に近い負荷をかけられるテストだと説明されることがあります。

研究面では、ニュージーランドのワイカト大学の研究グループ（Sellaら、2021年）が、ブロンコとほかの持久力テストの関係を調べています。対象はプロのセブンズ選手23人とユニオン選手133人です。[ワイカト大学のリサーチリポジトリ](https://researchcommons.waikato.ac.nz/handle/10289/15855)によると、主な結果は次のとおりです。

- ブロンコと、マルチステージ・シャトルラン（いわゆるビープテスト）の間には強い相関があった
- ブロンコと、Yo-Yo間欠性回復テスト レベル1の間には、さらに強い相関があった
- ユニオンの選手では、バックスのほうがフォワードよりブロンコの成績が良かった
- 結論として、著者らはブロンコがラグビーの体力テストとして有用であるとしている。一方で、各テストの成績の共通部分は大きくないため、結果は互いに置き換えられないとも述べている

ここから言えるのは、「ブロンコの結果は持久力の目安として使える」ということです。ただし、ブロンコが速いからといってほかのテストも同じように速いとは限りません。1つのテストの結果だけで、自分の体力全体を判断するのは避けたほうがよいでしょう。

また、2026年には、スーパーラグビーの選手462人（男子303人、女子159人）の10年分のブロンコ記録を分析し、パーセンタイル（順位の目安）やポジション別の基準値を示した研究が発表されています。Weakleyらによる研究で、Journal of Strength and Conditioning Researchに掲載されています。トップレベルのデータを集計した研究が出るほど、ブロンコは競技の現場で定着しているテストだと言えます。この記事では、基準値の具体的な数字は一次資料の確認が取れていないため引用しません。詳しく知りたい場合は、論文本体を確認してください。

## タイムの目安は資料によって違う

「何分なら合格か」は、とくに知りたい点だと思います。ただし、公式の合格ラインがあるわけではなく、資料ごとに目安が異なります。代表的な2つを紹介します。

[Topend Sports](https://www.topendsports.com/testing/tests/shuttle-1200m.htm)では、男子のタイムを次のように区分しています。

| 評価 | タイム |
| --- | --- |
| 世界記録レベル | 4分15秒未満 |
| エリート（プロ） | 4分15秒〜4分25秒 |
| 優秀 | 4分25秒〜4分35秒 |
| 非常に良い | 4分35秒〜4分45秒 |
| 良い | 4分45秒〜4分55秒 |
| 平均 | 4分55秒〜5分15秒 |

同ページには、プロのユニオンではフォワードがおおむね4分50秒〜5分10秒、バックスが4分20秒〜4分45秒という記述もあります。ただし、これは年代や競技レベルを限定した基準ではないため、大学生の部員が自分に当てはめるときは、あくまで参考値として扱うのが無難です。

もう1つは、ラグビー関連のブログ[Rugby Renegade](https://rugbyrenegade.com/the-bronco-test-what-it-is-and-what-you-should-be-aiming-for/)が示す「大まかな目安」です。クラブレベルのバックスは4分45秒〜5分15秒、フォワードは5分15秒〜5分45秒、一般の人は5分45秒以上とされています。ただし、このブログは出典となる研究や規格を示していないため、参考程度にとどめてください。なお、このブログには前節で触れた「1,500m」の記載もあります。

2つの資料を並べて見ると、同じ「エリート」でも数字に幅があり、年代・性別・競技レベル・測定環境によって変わることが分かります。大学生の部員にとって実用的なのは、次の考え方です。

- 他人との比較より、自分の過去の記録からの短縮を見る
- 同じ条件（ピッチの状態、時間帯、ウォームアップ）で測る
- ポジションごとの基準は、チームの測定記録やコーチの目安を優先する

バックスは速く、フォワードは遅い傾向があるとしても、これはポジションの特性による差です。フォワードのタイムが長いことが、そのまま「持久力が低い」ことを意味するわけではありません。自分のポジションの役割は、[ラグビーのポジション一覧と役割](https://rugbymania.jp/articles/rugby-position-ichiran-yakuwari-guide/)で確認できます。

## 測定でやりがちな失敗

ブロンコは全力で走る時間が4〜6分ほど続くため、準備と進め方を間違えると記録が安定しません。とくに起こりやすい失敗を整理します。

### 最初に飛ばしすぎる

最初のセットで全力を出しすぎて、3セット目以降に大きく失速するパターンです。Topend Sportsのページでも、ペース配分をしない前提のテストと説明されていますが、実際には、最後まで走り切れる範囲で速く入る意識が必要になる場合があります。1セット目と5セット目のタイムを記録しておくと、落ち込み方が分かります。

### 折り返しの減速が大きい

折り返しは30回あります。ラインを回り込んで走る形になると、距離が実質的に伸びます。足がラインに触れるかを確認し、急に止まって切り返す形を練習しておくと、ロスを減らせます。ただし、方向転換の負荷は膝や足首にかかります。慣れないうちは、全力で測る前に、ゆっくりの速度でフォームを確認しておくと安全です。

### ウォームアップが足りない

全力の走りを繰り返すため、準備不足だとハムストリングスなどを痛めるおそれがあります。ウォームアップは、[ラグビーのウォームアップと怪我予防](https://rugbymania.jp/articles/rugby-warmup-activate-injury-prevention-guide/)を参考に、ジョグ、ダイナミックストレッチ、徐々に速度を上げる走りの順で組み立てるとよいでしょう。ハムストリングスの怪我については、[ラグビーの肉離れ予防](https://rugbymania.jp/articles/rugby-hamstring-strain-prevention-guide/)も確認してください。

### 暑い日の無理な実施

夏場や暑い日に行う場合、熱中症のリスクがあります。気温が高い時期の測定は、時間帯や水分補給を調整してください。対策は[ラグビーの熱中症予防](https://rugbymania.jp/articles/rugby-heatstroke-prevention-summer-camp-guide/)にまとめています。体調が優れない日は、無理をせず測定日をずらす判断も大切です。

## ブロンコのタイムを伸ばす練習の考え方

ここからは、タイムを縮めるための考え方です。具体的なメニューの回数や距離は、体力や怪我の状況で変わるため、あくまで方向性として読んでください。

### 1. 走る量を増やす基礎期

シーズン前の早い時期には、ジョグやゆるいインターバルで走る土台を作る考え方があります。いきなり全力のシャトルを繰り返すと、故障のリスクが上がる場合があります。オフシーズンのトレーニング全体の組み立てについては、[ラグビーのオフシーズン筋トレメニュー](https://rugbymania.jp/articles/rugby-offseason-strength-training-menu/)で整理しています。

### 2. ブロンコに近い形のインターバル

テストの形式に近い走り（20m・40m・60mの往復）を、本数を減らして行う方法です。たとえば、1セットだけ全力で走り、休んでからもう1セット行うように、まず部分的に慣らす進め方があります。いきなり5セットを続けて走る必要はありません。

### 3. 方向転換の技術

折り返しのロスを減らすには、足をラインに置いて切り返す動きに慣れることが役立ちます。体を低くして減速し、一歩で切り返す動きは、タックルやディフェンスの動きにもつながります。

### 4. 回復とセットで考える

高強度のトレーニングは、回復が追いつかないと効果が出にくくなります。睡眠と食事を含めた回復の考え方は、[ラグビーの試合後の回復と睡眠](https://rugbymania.jp/articles/rugby-post-match-recovery-sleep-guide/)を参考にしてください。

## 結果の使い方｜記録を残して、シーズン中の指標にする

ブロンコの結果は、測って終わりにするより、記録として積み上げたほうが役立ちます。おすすめの記録項目は次のとおりです。

- 測定日、天候、場所（ピッチか人工芝か）
- 合計タイム
- セットごとのタイム（できれば）
- 体調やウォームアップの内容、気づいたこと

シーズン前、シーズン中盤、シーズン後に同じ条件で測れば、自分の変化が見えます。ただし、タイムが伸びないことと、試合でのパフォーマンスは別物です。試合では、ボールを持たない状況判断や、タックルの位置取りなど、タイム以外の要素が大きく影響します。

## 試合を見るときのヒント

ブロンコの考え方が分かると、試合の見方も変わります。大学ラグビーの試合では、後半の終盤に動きが落ちるチームと、最後まで運動量が保たれるチームがあります。自分のチームや気になるチームの試合の流れは、[関東対抗戦Aグループの日程・結果](https://rugbymania.jp/kanto-taiko-a/schedule/)や[順位表](https://rugbymania.jp/kanto-taiko-a/standings/)、[関西Aリーグの順位表](https://rugbymania.jp/kansai-a/standings/)で確認できます。後半の得点が多いチームを探すといった見方もできますが、得点の推移だけで体力の差を断定することはできません。あくまで、観戦のきっかけとして使ってください。

## まとめ

ブロンコテストは、20m・40m・60mの折り返しを5セット（合計1,200m）全力で走り、合計タイムを測る、ラグビーで広く使われる持久力テストです。研究では、ほかの持久力テストと強い相関があり、ラグビーの体力テストとして有用だとされています。ただし、各テストの結果は互いに置き換えられません。

タイムの目安は資料によって差があるため、他人との比較よりも、自分の記録の推移を見ることが実用的です。測定時は、ペース配分、折り返しの技術、ウォームアップ、気温に注意してください。

最後に、この記事のポイントを整理します。

1. ブロンコは1,200mのシャトルランで、折り返しは合計30回
2. タイムの目安は資料により異なる。チームの基準を優先する
3. 自分の過去の記録からの変化を見る
4. 全力で走るテストなので、ウォームアップと暑さ対策を怠らない
5. 結果だけで、ポジションの適性や試合の出来を決めつけない
