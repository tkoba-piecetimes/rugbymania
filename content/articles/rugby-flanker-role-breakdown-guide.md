フランカーに配属された、あるいはほかのポジションからコンバートされた新入部員が最初に抱くのは、「フランカーは結局、何をするポジションなのか」「6番と7番はどう違うのか」という疑問ではないでしょうか。スクラムでは目立たず、ラインアウトでもジャンパーとは限らず、試合ではタックルとブレイクダウン（接点での攻防）に追われる。役割が多岐にわたるぶん、何から練習すればよいのか見えにくいポジションです。この記事では、World Rugby（ワールドラグビー）のコーチング資料（Passport）の機能的役割分析、競技規則、RugbyPassなどの解説をもとに、フランカーの役割、6番と7番の違い、接点で守るべきルール、練習の組み立て方を整理します。ここで紹介する内容は一般的に紹介されている考え方であり、所属チームの監督・コーチの指導方針が優先される点はあらかじめご了承ください。

## フランカーの役割をおさえる

### スクラムの両翼として

フランカーはバックロー（フォワードの最後列）の両翼にあたり、背番号は6番と7番です。J SPORTSのポジション解説でも、フランカーはボール争奪戦やラックでの競り合いで活躍する選手が求められるポジションとして紹介されています。

スクラムでの働きについて、World Rugby Passportの機能的役割分析（Flankers）には、次のような項目が挙げられています。

- 個人としても、後列全体としても、圧力をかけたり受けたりしながら強く安定した体の位置を保つこと
- 前後に制御された動きができること
- ロックおよびプロップと、強く有効で反則にならないバインド（組み方）を保つこと
- ロックと一体になってプロップを支えること
- ナンバーエイトへボールを送り出すこと
- 後列からの攻撃オプションに参加できること

フランカーはスクラムを「押す人」というよりも、前列と第2列を支えて形を崩さず、ボールが出たらすぐ次の仕事に移る人、という読み方ができます。競技規則第19条19.7dでは、スクラムのほかの選手は少なくとも片腕でロックの体にバインドすると定められています。また19.11dには、スクラムの間、バインドは最初に組んだ位置のまま保たれるとあります。スクラムの組み方そのものは[ラグビーのスクラム：組み方と練習のポイント](https://rugbymania.jp/articles/rugby-scrum-technique-practice-guide/)で詳しく扱っています。

### ラインアウトでの仕事

同じPassportの分析では、フランカーのラインアウトでの役割として、相手に対する優位の確保、サポートを受けてのジャンプ、空中でのキャッチ、味方へのクリーンな受け渡し、ドリブンラインアウトへの参加、ボールの奪取、ラインアウトの前後でのアタック（ピールと呼ばれる動き）などが挙げられています。RugbyPassのブラインドサイドフランカーの解説でも、ロックに次ぐ3番目のジャンプの選択肢となる場合があること、爆発的なジャンプや味方を持ち上げる力が求められることが紹介されています。ロックのジャンプとリフトの考え方は[ラグビーのロック練習法](https://rugbymania.jp/articles/rugby-lock-lineout-scrum-training-guide/)を、投げ手の側の事情は[ラグビーのフッカー ラインアウト・スローイングのコツと練習法](https://rugbymania.jp/articles/rugby-hooker-lineout-throwing-guide/)をあわせて読むと、フランカーが組になる相手の動きを理解しやすくなります。

### オープンプレー（スクラム・ラインアウト以外の場面）

フランカーの活動量が最も多くなるのは、セットプレー以外の場面です。Passportの分析には、次の項目が並んでいます。

- ボールを持って前進し、陣地を獲得すること
- 左右へさまざまなパスをすること
- 攻撃時にスペースを見つけて使うこと、守備時にスペースを埋めること
- 攻撃でも守備でも味方をサポートすること
- さまざまな角度からタックルすること
- ラックやモールで状況に応じた判断と実行をすること
- セットプレーのあと、次の役割へ素早く切り替えること
- フォワードとバックスの間で攻撃の継続性を保つこと

つまり、フランカーは「タックルとジャンパーだけ」のポジションではなく、攻撃にも守備にも絡み続けるポジションです。ポジション全体の整理は[ラグビーのポジション一覧と役割を解説](https://rugbymania.jp/articles/rugby-position-ichiran-yakuwari-guide/)で確認できます。

## 6番と7番、ナンバーエイトの違い

### ブレイクダウンが主な分かれ目

RugbyPassの解説（Sam Smith氏、2022年8月9日公開）などでは、6番はブラインドサイドフランカー、7番はオープンサイドフランカーと呼ばれ、ブレイクダウンへの関わり方が両者の主な違いだと説明されています。以下の表は、Passportの機能的役割分析、RugbyPassの2本の解説記事（ブラインドサイドの解説は2022年、オープンサイドの解説は2020年公開）を参考に、編集部が整理した傾向です。実際の役割はチームの戦術、選手の体格、その日の相手によって変わります。

| ポジション | 一般的に紹介されている傾向 | 試合で見られやすい場面 |
| --- | --- | --- |
| 6番（ブラインドサイド） | 体格が大きめの選手が起用される傾向があり、ボールを持って前に出る役割や、狭いエリアでの繰り返しのタックルが紹介されている | タッチライン側の狭いスペースでのキャリー、ラインアウトの3人目のジャンパー |
| 7番（オープンサイド） | ブレイクダウンで守備側の妨害や相手ボールの奪取（ジャッカルと呼ばれる動き）に絡み、攻撃側のブレイクダウンでも貢献することが重視される傾向がある | 接点への最初の到着、広いスペースでのサポートランニング |
| 8番（ナンバーエイト） | スクラム最後尾でボールを制御し、フォワードとバックスをつなぐ働きが強調される傾向がある | スクラムからの持ち出し、中盤でのキャリー |

この表はあくまで傾向であり、「6番は必ずこう、7番は必ずこう」と決まっているわけではありません。大学ラグビーでは、体格や人数のバランスから、6番と7番の役割分担がチームごとに異なる場合があります。ナンバーエイトの役割はPassportの分析で、スクラムでボールを制御しスクラムハーフを守ること、ラインアウトでの攻撃オプション、フォワードとバックスをつなぐ働きなどが挙げられています。

### オープンサイドに求められるものの一例

RugbyPassのオープンサイドフランカーの解説（Alex Shaw氏、2020年4月10日公開）では、オープンサイドに求められる要素として、ブレイクダウンでの強さ、ボールを持った動きとつなぎ、機動力、1対1のタックル、そして試合を読む力の5つが挙げられています。特に「接触に入るか、ジャッカルとして飛び込むか」の判断が、上位の選手と他の選手を分けると述べられています。ここで大切なのは、フィジカルだけでなく判断が重視されていることです。体の大きさに自信がなくても、状況判断で貢献できる余地があると読み取れます。

## 接点（ブレイクダウン）で知っておきたい競技規則

フランカーは、ほかのポジションよりも反則を取られやすい場面に身を置きます。ルールを知らないまま接点に入ると、チームにペナルティを与える原因になりかねません。ここでは、World Rugby競技規則のうち、フランカーに特に関係する条文を要約します。規則は改正される場合があるため、最新の内容は日本ラグビーフットボール協会のページで確認してください。

### タックルのあと（第14条）

| 条文 | 内容の要約 |
| --- | --- |
| 14.5b | タックラーは、双方が地面に倒れたら、ボールとボールキャリアーをすぐに放す |
| 14.5c | タックラーは、タックルされた選手とボールからすぐに離れるか、立ち上がる |
| 14.5d | タックラーは、ボールをプレーしようとする前に、自分の足で立っている必要がある |
| 14.8a | その他の選手も、立ったままで、ボールとボールキャリアーをすぐに放す |
| 14.8b | ボールを争うときは、立ったままプレーする |
| 14.8c | タックルのあと、ボールをプレーする前に、自陣のトライラインの方向から到着する |

フランカーが自分でタックルしたあとにすぐボールに働きかけたくなる場面は多いのですが、まず放して、立ち上がってからプレーするという順序が条文で示されています。「タックル後に倒れたまま手を出す」動きは反則の対象になりやすいので、立ち上がる速さそのものを練習の対象にする価値があります。

### ラックへの参加（第15条）

| 条文 | 内容の要約 |
| --- | --- |
| 15.2 | 双方のチームの選手が少なくとも1人ずつ、立ったままボールの上で接触したときにラックが成立する |
| 15.4 | 各チームのオフサイドラインは、ラックに参加している最後尾の選手の足を通り、ゴールラインと平行に引かれる |
| 15.5 | 後から参加する選手は、立った状態で、自分たちのオフサイドラインの後ろから加わる |
| 15.6 | 最後尾の選手と並ぶことはできるが、それより前から加わってはいけない |
| 15.7 | 味方または相手にバインドする。バインドは、体のほかの部分が触れるのと同時か、それより先に行う |
| 15.8 | すぐにラックに加わるか、オフサイドラインの後ろに下がる |
| 15.13 | ラックの全選手は、横に並んでいるだけでなく、ラックの中にいるかバインドしている必要がある |

これらは、後から接点に走り込むフランカーが一番気をつけたい条文です。最後尾の選手より前や横から入ってしまう動きや、バインドが遅れて体が先に当たってしまう動きは、ペナルティにつながる場合があります。ボールを奪う動きだけでなく、入り方の整った状態でボールに働きかけることが前提になります。

### 危険なプレー（第9条）

第9条には、ラックやモールでの危険なプレーとして、肩のラインより上への接触の禁止（9.20b）、ラックやモールを故意に崩すことの禁止（9.20c）、相手を転がしたり引いたり、ひねったりすることの禁止（9.20d）、相手の上に体重を落とすことや下半身を狙うことの禁止（9.20e）などが定められています。相手を後ろへ押し出すクリーンアウト自体は認められていますが、押し方に制限があります。さらに9.13には、頭部への接触を伴うタックルや、オープンプレーでの制裁ラインより上へのタックルが、危険なタックルとして示されています。

2026年にはタックルの高さに関する通達も出ています。大学ラグビーでどの制裁ラインが当てはまるかは、[ラグビーのルール改正を2026年の日本協会通達で整理](https://rugbymania.jp/articles/rugby-rule-kaisei-2026-guide/)で整理しているので、あわせて確認してください。フランカーはタックルの回数が多くなりやすいポジションです。高さの基準は、フォームを確認する際に意識しておきたい点です。

## フランカーの練習の組み立て方

以下は、編集部が上記の資料の考え方を参考に組み立てた例であり、特定のチームの実践例ではありません。チームの練習日程や体の状態に合わせて調整してください。

### 練習の優先順位の考え方

どれも大切に見えますが、最初に固めたいのは次の順番だと整理できます。

1. **タックルの基本フォームと安全な高さ**: [ラグビーのタックル練習とコツ](https://rugbymania.jp/articles/rugby-tackle-practice-tips/)で扱っている段階的な練習から始めます。回数をこなすポジションだからこそ、低く入る、頭の位置を守るといった基本を丁寧に確認します。
2. **立ち上がりの速さ（タックルのあと）**: 第14条のとおり、立ってからボールをプレーします。タックルのあと、放す、離れる、立つという動作を連続で行う練習が土台になります。
3. **ラックへの入り方**: 第15条のとおり、オフサイドラインの後ろから、バインドして入ります。入る角度と、バインドの先行を、ボールなし・パッド使用などの軽い負荷で確認します。
4. **サポートランニング**: ボールキャリアーの近くで、パスを受けられる位置に動く練習です。Passportの分析にある、攻撃でも守備でも味方をサポートするという項目に対応します。
5. **スクラムとラインアウトの連携**: 担当するポジション（6番か7番か、ジャンパーを兼ねるか）に応じて、ロック・ナンバーエイトと動きをそろえます。

### 1週間の回し方の例

1. **タックルとフォーム確認の日**: 軽い負荷でタックルの姿勢と立ち上がりを確認します。
2. **接点の日**: ラックへの入り方、バインド、オフサイドラインの位置を、ルールの条文と照らし合わせながら確認します。
3. **セットプレーの日**: スクラムとラインアウトでの動きを、ロックやナンバーエイトとそろえます。
4. **動きながらの判断の日**: 攻撃から守備への切り替えと、接点に「入る」か「下がる」かの判断を、制限付きの試合形式で確認します。
5. **試合想定の日**: 疲労のある状態で、タックル・ラック・サポートの連続動作を通して行います。

### 記録のつけ方

練習ノートには、タックル後に立ち上がるまでの動きの気づき、ラックへ入るときに指摘された点（入る角度、バインドの遅れ、オフサイドの位置）、サポートで間に合わなかった場面、レフリーの笛の理由などを書いておくと、数週間単位で変化を振り返りやすくなります。数字は他の選手と比べるためではなく、自分の傾向を知るために使うのがよいでしょう。

## 体づくりとケガの予防

フランカーは、タックルの衝撃、ラックでの接触、走る距離が重なるポジションです。首・肩・体幹・下半身をバランスよく鍛えるメニューは[ラグビーのオフシーズン筋トレメニュー](https://rugbymania.jp/articles/rugby-offseason-strength-training-menu/)に、増量や食事の考え方は[ラグビーの食事・増量メニュー](https://rugbymania.jp/articles/rugby-nutrition-bulk-up-guide/)にまとめています。頭を打った場合の対応は[ラグビーの脳震盪対応と段階的競技復帰](https://rugbymania.jp/articles/rugby-concussion-return-to-play-guide/)で、手の怪我は[ラグビーの突き指・靭帯損傷の予防](https://rugbymania.jp/articles/rugby-finger-sprain-ligament-injury-prevention/)で確認できます。痛みや違和感がある場合は練習量を減らし、トレーナーや医療機関に相談してください。

練習で気をつけたい点は次のとおりです。

- **勢いだけで接点に入らない**: ルールの条文に沿った入り方を優先し、危険なプレーとなる動きを避けます。
- **疲れている状態での接点練習は負荷を調整する**: 疲労がたまると姿勢が崩れやすくなる場合があります。
- **指導者の方針を優先する**: 入り方、バインドの形、ジャッカルの狙い方には複数の考え方があります。ここで紹介した内容は考え方の一例として使ってください。

## 所属リーグ・対戦相手を確認して試合の準備に活かす

フランカーの練習の成果は、試合で試されます。まず自分たちの所属リーグと対戦相手の位置づけを確認しておくと、準備の見通しが立ちやすくなります。関東大学対抗戦Aグループの大学は[大学一覧](https://rugbymania.jp/kanto-taiko-a/teams/)から、順位は[順位表](https://rugbymania.jp/kanto-taiko-a/standings/)から確認できます。リーグ戦1部は[リーグ戦1部の順位表](https://rugbymania.jp/kanto-league-1/standings/)、関西Aリーグは[関西Aリーグの順位表](https://rugbymania.jp/kansai-a/standings/)、九州は[九州Aリーグの順位表](https://rugbymania.jp/kyushu-a/standings/)で確認できます。気になる大学の試合日程や結果は、各チームページからたどれます。

相手チームの試合を見るときは、背番号6・7・8の選手がタックルのあとにどう動くか、ラックにどの角度から入っているかを観察してみてください。文字で読むより、試合で番号を追うほうが、接点での役割のイメージがつかみやすくなります。用語に迷ったときは[ラグビー用語集（初心者向け）](https://rugbymania.jp/articles/rugby-glossary-beginner-guide/)で、ブレイクダウンやラックといった言葉を確認できます。

## まとめ

フランカーは、スクラムの両翼として安定を支え、ラインアウトでは役割に応じてジャンプやリフトに加わり、セットプレー以外の場面ではタックル・接点・サポート・つなぎを担い続けるポジションです。6番と7番の違いはブレイクダウンへの関わり方が主な分かれ目と紹介されていますが、実際の役割分担はチームの戦術や選手の体格によって変わります。接点では、タックル後に放して立ち上がること（第14条）、オフサイドラインの後ろから、バインドして入ること（第15条）、危険なプレーを避けること（第9条）が土台になります。規則は改正されることがあるため、日本協会の最新の競技規則と大会要項の確認を習慣にしましょう。
